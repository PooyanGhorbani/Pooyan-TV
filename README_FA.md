# Pooyan TV v0.1 — نسخهٔ پایه برای Android TV

**وضعیت خروجی: سورس قابل ساخت؛ APK کامپایل‌شده و تست روی تلویزیون در این محیط موجود نیست.**

این پروژه از سورس Pooyan TV 4.0 قبلی ساخته شده و از این به بعد با شماره‌گذاری **v0.1، v0.2، v0.3 ...** ادامه پیدا می‌کند. در واقع امکانات قبلی حذف نشده‌اند؛ شمارهٔ نسخه از نو شروع شده است.

## امکانات موجود در v0.1

- انتخاب از هفت منبع فارسی: پارسیموندو، بابک فیلم، تلوبیون، تماشاخونه، Pardeh TV، سیتاسو و Namakade.
- کنترل با ریموت/D-pad و نشانگر مجازی داخل سایت.
- WebView برای نمایش خود سایت؛ پخش‌کنندهٔ اختصاصی **Media3** برای لینک‌های مستقیم HTTPS از نوع MP4، WebM، HLS و DASH.
- زیرنویس خارجی SRT/VTT با URL مستقیم، انتخاب کیفیت/ترک صدا/زیرنویس در منابع سازگار، سرعت پخش، عقب/جلو بردن.
- تاریخچه و ادامهٔ تماشای محلی، علاقه‌مندی‌ها، پوسترهای صفحات بازدیدشده (در صورت ارائهٔ پوستر هم‌دامنه)، پیشنهادهای محلی و جست‌وجوی عنوان.
- جست‌وجوی وب از Bing پس از انتخاب کاربر. **هیچ API رسمی یا آرشیو یکپارچهٔ تضمین‌شده از سایت‌ها وجود ندارد.**
- تغییر آدرس سایت‌های تعریف‌شده، لینک شخصی Namakade در تنظیمات دستگاه، و به‌روزرسانی اختیاری فهرست آدرس منابع از HTTPS JSON مورداعتماد.
- **جدید:** ابزار «بررسی اتصال سایت‌ها» در پایین صفحهٔ اصلی و تنظیمات؛ پاسخ HTTP هر سایت را بدون اطلاعات حساب کاربری نشان می‌دهد. **این تست تأیید پخش فیلم نیست.**
- **اصلاح:** پس از رفتن برنامه به پس‌زمینه و بازگشت، پخش‌کنندهٔ اختصاصی از موقعیت اخیر برمی‌گردد؛ وضعیت Pause و سرعت پخش حفظ می‌شوند. فیلم تمام‌شده از ابتدا آغاز می‌شود.
- **اصلاح:** هنگام برگشتن به صفحهٔ اصلی، ویدئوهای HTML5 داخل وب مخفی تا حد امکان متوقف می‌شوند.
- **اصلاح:** بستن Executorهای دریافت پوستر/JSON/تشخیص اتصال موقع خروج از برنامه.
- **اصلاح ساخت:** گردش‌کار GitHub Actions از Gradle رسمی نصب‌شده توسط `gradle/actions/setup-gradle` استفاده می‌کند؛ bootstrapper غیررسمی حذف شده است.

## محدودیت‌های مهم

- بعضی سایت‌ها ممکن است ثبت‌نام، حق اشتراک، پخش‌کنندهٔ اختصاصی، DRM یا محدودیت منطقه‌ای داشته باشند. برنامه این محدودیت‌ها را دور نمی‌زند.
- اگر صفحه فقط به کمک کوکی، DRM، iframe محدود یا اسکریپت خاص پخش شود، Media3 ممکن است نتواند آن را باز کند؛ از همان WebView استفاده کن.
- در چین ممکن است برخی سایت‌ها یا YouTube/Bing بدون VPN/پروکسی در دسترس نباشند.
- پوسترهای اصلی کل آرشیو سایت‌ها از قبل وارد اپ نشده‌اند. فقط دادهٔ مجازِ صفحاتی که باز کرده‌ای ذخیره می‌شود.
- **DeepSeek API در v0.1 وصل نشده است**؛ ابتدا ساخت و پخش واقعی را تأیید می‌کنیم. کلید API هیچ‌وقت نباید داخل APK قرار بگیرد. در نسخه‌های بعد می‌توان با یک سرور واسط و با رضایت کاربر قابلیت پیشنهاد یا گفت‌وگو را اضافه کرد.

## روش پیشنهادی ساخت APK: GitHub Actions

1. محتوای همین پوشه را در **ریشهٔ یک مخزن خصوصی GitHub** قرار بده. توجه کن که پوشهٔ مخفی `.github` نیز منتقل شود.
2. در مخزن: `Actions > Build Pooyan TV APK > Run workflow` را اجرا کن. اگر `Actions` غیرفعال باشد، ابتدا آن را برای مخزن فعال کن.
3. گردش‌کار JDK 17، Android SDK 35 و **Gradle 8.9 رسمی** را نصب و ابتدا تست آفلاین، سپس `assembleDebug` را اجرا می‌کند.
4. اگر ساخت موفق شد، از بخش Artifacts فایل `pooyan-tv-v0.1-debug-apk` را دریافت کن. داخل ZIP خروجی `app-debug.apk` است.
5. **APK را تنها بعد از موفقیت واقعی Build می‌توان قابل‌نصب دانست.** GitHub Actions در این محیط اجرا نشده است.

### ساخت محلی با Android Studio

- نیاز: JDK 17، Android SDK Platform 35، Build Tools 35.0.0، Gradle 8.9 و اینترنت برای پلاگین Android Gradle 8.7.3 و Media3 1.6.1.
- پوشه را در Android Studio باز کن. به دلیل نبود Gradle wrapper رسمی در این بسته، Gradle 8.9 محلی/تنظیم‌شده در Android Studio لازم است.
- Sync، سپس `Build > Build APK(s)`؛ یا در سیستم دارای Gradle 8.9 و `ANDROID_HOME`: `bash scripts/build-debug.sh`.
- محل پیش‌بینی‌شدهٔ خروجی: `app/build/outputs/apk/debug/app-debug.apk`.

## نصب روی Xiaomi TV با ADB

بعد از اینکه APK واقعاً ساخته شد، با **Android Platform Tools** این دستورات را در رایانه اجرا کن (به‌جای `TV_IP`، IP فعلی تلویزیون را وارد کن):

```bash
adb connect TV_IP:5555
adb install -r app-debug.apk
adb shell monkey -p com.pooyan.namakadetv 1
```

شناسهٔ برنامه همان `com.pooyan.namakadetv` است. **versionName = 0.1** و برای ارتقا از پروژه‌های قبلی **versionCode = 5** گذاشته شده. اگر امضای APK با نسخهٔ نصب‌شده فرق داشته باشد، نصبِ ارتقایی ممکن نیست. برای رفع این مشکل بدون بررسی، برنامهٔ قبلی را حذف نکن چون داده‌های محلی پاک می‌شوند.

## آزمایش روی دستگاه — ترتیب پیشنهادی

1. اپ از قسمت TV Apps باز شود و با ریموت قابل کنترل باشد.
2. گزینه «◎ بررسی اتصال سایت‌ها» را اجرا کن و نتیجهٔ شبکه را بررسی کن (صرفاً اتصال اولیه).
3. از هر سایت یک فیلم را **در WebView** آزمایش کن. ثبت‌نام، محدودیت کشور و وضعیت پخش را یادداشت کن.
4. اگر لینک مستقیم تشخیص داده شد، `Menu > پخش‌کننده اختصاصی` را امتحان کن.
5. در میانهٔ ویدئوی Media3 از برنامه خارج شو و برگرد؛ موقعیت باید حفظ شود. با Pause نیز امتحان کن.
6. پوسترهای صفحات بازدیدشده، جست‌وجوی محلی، علاقه‌مندی و Back را بررسی کن.
7. برای خطاها از `docs/TV_TEST_CHECKLIST_FA.md` و Logcat استفاده کن؛ قبل از ارسال لاگ لینک‌های شخصی/توکن را پاک کن.

## نتیجهٔ بررسی این بسته

- `bash scripts/verify-offline.sh`: **۱۰۷ بررسی** در هفت دسته موفق بود.
- `javac` تمامی کلاس‌های **بدون Android SDK** مربوط به تست را کامپایل کرد.
- سینتکس **۱۵ فایل Java** توسط Java Compiler Parser بررسی شد؛ XML مانیفست معتبر بود.
- **Build واقعی Gradle/Android/Media3: اجرا نشده**؛ Android SDK و Gradle در این محیط وجود ندارند و اتصال به سرور دانلود ابزارها برقرار نیست.
- **APK: تحویل داده نشده**؛ **تست فیزیکی Xiaomi: انجام نشده**.

## امنیت و حریم خصوصی

- URL شخصی Namakade و کلید DeepSeek داخل سورس و فایل APK پیش‌فرض نیست.
- لینک شخصی فقط روی همان تلویزیون در تنظیمات ثبت می‌شود؛ خروجی‌های Logcat را قبل از اشتراک بررسی کن.
- منابع عمومی از دامنهٔ خودشان باز می‌شوند. کوکی‌های سایت‌ها برای سایر دامنه‌ها به پخش‌کننده اختصاصی کپی نمی‌شود.
- فایل JSON به‌روزرسانی اختیاری است، و برای سایت‌های از پیش تعریف‌شده فقط مسیرهای HTTPS هم‌دامنه را می‌پذیرد.
