# Pooyan TV v0.2 — نسخهٔ Native Cinema برای Android TV

**وضعیت فعلی:** نسخهٔ آزمایشی 0.2 با JDK 17، Gradle 8.9 و Android SDK 35 در GitHub Actions ساخته شد. آزمون‌های آفلاین و Lint موفق‌اند. نصب موازی و آزمون واقعی روی Xiaomi MiTV-MFFU0 با Android 14 انجام شد. جزئیات و محدودیت‌ها در [گزارش آزمون](docs/V0_2_TEST_RESULTS_FA.md) ثبت شده‌اند.

## تغییر کلیدی: دیگر مرورگر نیست

صفحهٔ اصلی و صفحات داخلی کاملاً Native Android هستند. هیچ `WebView` یا نوار انتخاب وب‌سایت نداریم. کاربر به‌جای سایت، فیلم یا سریال را می‌بیند، جزئیات را باز می‌کند و فقط برای فیلم دارای لینک مستقیم معتبر دکمهٔ پخش می‌بیند.

- صفحهٔ اصلی با ردیف پوسترهای فیلم و سریال، دسته‌بندی‌های محبوب، اکشن، کمدی، انیمیشن، درام و ...
- جست‌وجوی جهانی بر اساس نام اثر با صفحهٔ نتایج فیلم و سریال
- نمایش جزئیات اثر و فهرست قسمت‌های سریال در صورت ارائهٔ متادیتا
- بخش **تماشای رایگان** با شش فیلم کوتاه آزاد Blender و پخش مستقیم Media3
- ذخیرهٔ علاقه‌مندی‌ها، کتابخانهٔ لینک‌های شخصی و ادامهٔ تماشا روی تلویزیون
- کنترل D-pad و Back، بدون موس مجازی
- پخش MP4 / WebM / HLS / DASH و زیرنویس‌های مستقیم SRT/VTT از طریق `PlayerActivity` موجود
- رابط فارسی و انگلیسی برای نام‌های بین‌المللی؛ همهٔ اطلاعات محلی بدون حساب کاربری Pooyan TV

## کاتالوگ و پخش: نکتهٔ ضروری

کاتالوگ عمومی از **Cinemeta، افزونهٔ رسمی Stremio** (https://v3-cinemeta.strem.io/manifest.json) می‌آید. این سرویس فیلم‌ها، سریال‌ها، پوسترها و متادیتا ارائه می‌دهد؛ **لینک پخش فیلم‌های تجاری ارائه نمی‌دهد**. نمایش پوستر به معنی قابل‌تماشا بودن نیست.

برای محتوای دارای حقوق نشر، فقط در صورتی پخش ممکن است که کاربر لینک مستقیم HTTPS مجاز MP4/WebM/HLS/DASH داشته باشد و آن را روی همان دستگاه ذخیره کند. قفل اشتراک، DRM، کوکی‌های خصوصی و دسترسی محدود منطقه‌ای دور زده نمی‌شوند. لینک‌های شخصی هیچ‌وقت داخل APK پیش‌فرض یا GitHub منتشر نمی‌شوند.

شش اثر آزاد از سرور سازنده با ذکر مجوز و اعتبار ارائه شده‌اند: **Big Buck Bunny، Sintel، Tears of Steel، Spring، Sprite Fright، Agent 327**. منابع: Blender Studio (https://studio.blender.org/films/) و https://video.blender.org. مجوز آثار از CC BY 3.0 و CC BY 4.0 است؛ عنوان و حق مؤلف فیلم‌ها متعلق به پدیدآورندگان است. فیلم‌ها در APK بسته‌بندی یا بازتوزیع نشده‌اند؛ پخش به دسترس‌بودن منبع وابسته است.

در اینترنت چین ممکن است Cinemeta، تصاویر ویدئوها یا video.blender.org در دسترس نباشند؛ برنامه خطا را نشان می‌دهد و در حالت اتصال ناقص فقط فهرست‌های کش‌شده و کارت‌های آثار آزاد قابل مشاهده‌اند. داشتن کارت به معنی دسترسی به فیلم نیست.

## ساخت APK در GitHub Actions

1. کل محتوای این پروژه، شامل پوشهٔ مخفی `.github`، در ریشهٔ مخزن `PooyanGhorbani/Pooyan-TV` قرار بگیرد. از محتویات ZIP استخراج‌شده استفاده کن، نه آپلود یک فایل ZIP تنها.
2. در GitHub بخش **Actions → Build Pooyan TV v0.2 Preview → Run workflow** را اجرا کن.
3. اجرای GitHub Actions ابتدا `scripts/verify-offline.sh`، سپس `assembleDebug` و `lintDebug` را انجام می‌دهد.
4. **فقط بعد از نتیجهٔ سبز** artifact با نام `Pooyan-TV-v0.2-preview-APK` را دانلود کن؛ در آن `app-debug.apk` است.
5. فایل ساخته‌شده باید روی Android TV واقعی نصب و با ریموت و پخش ۲ فیلم آزاد و جست‌وجو و تاریخچه آزمایش شود.

نسخهٔ آزمایشی دارای `versionName 0.2`, `versionCode 6` و `debug applicationId = com.pooyan.namakadetv.preview` است. این شناسهٔ جداگانه عمداً انتخاب شده تا **کنار v0.1** نصب شود و امضای Debug متفاوت، داده‌های برنامهٔ قبلی را از بین نبرد. داده‌های نسخهٔ 0.1 به‌طور خودکار به Preview منتقل نمی‌شوند.

**امضای نسخهٔ پایدار:** پیش از انتشار عمومی باید کلید امضای ثابت و خصوصی برای نسخهٔ نهایی ایجاد و با secrets امن GitHub Actions مدیریت شود؛ هرگز keystore یا گذرواژه را در مخزن Public قرار نده.

## نصب و آزمایش روی Xiaomi Android 14

پس از دریافت APK، رایانهٔ ویندوز باید ADB و دسترسی مجاز به تلویزیون داشته باشد. `scripts/Install-PooyanTV-v0.2.ps1` برای نصب آزمایشی در کنار نسخهٔ 0.1 آماده است:

```powershell
.\scripts\Install-PooyanTV-v0.2.ps1 -TvAddress "TV_IP:5555" -ApkPath "C:\path\app-debug.apk"
```

این اسکریپت برنامه‌ای حذف نمی‌کند. اگر تلویزیون درخواست مجوز ADB کند، خود کاربر باید تأیید کند. IP و دادهٔ خصوصی را وارد فایل‌های مخزن عمومی نکن.

### چک‌لیست تست واقعی

- اجرا بدون crash و نمایش صفحهٔ Native و منوهای قابل حرکت با D-pad
- دریافت پوسترهای Cinemeta (در منطقهٔ چین، وضعیت اتصال جداگانه ثبت شود)
- جست‌وجوی فیلم و سریال و بازشدن صفحهٔ جزئیات
- نمایش سریال و قسمت‌ها
- پخش MP4 از یکی از آثار Blender و نمایش تمام‌صفحه
- کنترل مکث، جلو/عقب، زیرنویس و ذخیرهٔ ادامهٔ تماشا
- مسیر بدون منبع پخش پیام درست بدهد؛ نمایش «قابل پخش» برای فیلمی که لینک ندارد ممنوع
- نصب v0.2 نباید نصب v0.1 یا داده‌های آن را حذف کند
