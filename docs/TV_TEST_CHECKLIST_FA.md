# چک‌لیست آزمایش Pooyan TV v0.1 روی Xiaomi Android 14

## قبل از تست
- [ ] فایل APK با Gradle 8.9 / Android SDK 35 واقعاً ساخته شده و Build موفق است.
- [ ] نصب روی تلویزیون از `adb install -r` یا Android Studio بدون خطا انجام شده.
- [ ] اپ با کنترل ریموت، کلیدهای جهت، OK، Menu و Back کار می‌کند.
- [ ] منوی بررسی اتصال هفت منبع جواب می‌دهد، بدون اینکه خودبه‌خود فیلمی اجرا کند.

## عملکرد برنامه
- [ ] WebView هنگام رفتن به خانه، صدای ویدئوهای HTML5 را متوقف می‌کند.
- [ ] Media3 ویدئوی MP4 یا HLS مجاز را باز می‌کند (در صورت داشتن لینک مستقیم سازگار).
- [ ] بعد از ۱ دقیقه تماشا، Home و بازگشت، همان ثانیه ادامه می‌دهد.
- [ ] وقتی پیش از خروج Pause شده، پس از بازگشت همچنان Pause می‌ماند.
- [ ] سرعت انتخابی پس از پس‌زمینه رفتن حفظ می‌شود.
- [ ] بعد از تمام شدن فیلم، پخش از ابتدا آغاز می‌شود.
- [ ] جست‌وجوی فارسی، علاقه‌مندی، پوسترهای صفحات بازدیدشده و Back درست کار می‌کنند.
- [ ] زیرنویس و کیفیت فقط در صورت وجود ترک‌های مرتبط فعال می‌شوند.
- [ ] محدودیت‌های ورود یا DRM دور زده نمی‌شوند.

## گزارش خطا (پس از حذف اطلاعات شخصی)

```bash
adb logcat -c
adb shell monkey -p com.pooyan.namakadetv 1
adb logcat -d -s AndroidRuntime:E chromium:E ExoPlayerImpl:E MediaCodec:E > pooyan-tv-log.txt
```

لاگ را قبل از ارسال از نظر توکن‌های لینک شخصی و مشخصات حساب بررسی کن.
