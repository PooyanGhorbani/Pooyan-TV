# فهرست آزمایش Pooyan TV FarsiPlex v0.4.1 روی تلویزیون Xiaomi

1. نصب APK آزمایشی فقط از مسیر مجاز، بدون پاک‌کردن نسخهٔ اصلی؛ بررسی امضا و شناسهٔ برنامه
2. صفحهٔ اصلی با دو ردیف فیلم/سریال و تصاویر از farsiplex.com؛ تست روی اینترنت خانه در چین
3. کنترل ریموت: بالا/پایین/چپ/راست/OK/Back، فوکوس واضح و بدون قطع‌شدن برنامه
4. ورود به فیلم «Harchi To Begi» و سریال «Taxi» (اگر هنوز در فهرست عمومی هستند)
5. دریافت فهرست قسمت‌ها و رفتن از قسمت به صفحهٔ سریال
6. جست‌وجوی «Taxi» و یک عبارت فارسی؛ اطمینان از نبود درخواست‌های بی‌رویه
7. علاقه‌مندی‌ها پس از بستن برنامه و راه‌اندازی دوباره
8. صفحهٔ بعد فیلم و سریال؛ رفتار مناسب در HTTP 404 / تغییر قالب / قطعی DNS
9. اضافه‌کردن لینک **مجاز و مستقیم** HLS/MP4، پخش داخل Media3، کنترل ریموت، ثبت ادامهٔ تماشا
10. بررسی Logcat و ترافیک: بدون رمز عبور، کوکی شخصی یا تلاش برای دورزدن DRM

**ممنوعیت ادعای موفقیت:** بدون تست واقعی API و ویدئو، پخش فیلم‌های FarsiPlex تأیید نشده است.

11. پس از ورود به «فیلم‌ها»، فوکوس خودکار روی اولین کارت قرار بگیرد؛ با چپ/راست از کارت ۱ به ۲ و با پایین به ردیف بعد حرکت کند؛ در صفحهٔ اصلی هم جابه‌جایی بین دو ریل آزمایش شود.
12. صفحهٔ جزئیات حاوی `<video src>` یا `<video><source src>` عمومی را تست کن؛ تنها با URL واقعی مستقیم HTTPS دکمهٔ پخش فعال شود و Media3 فریم و صدا پخش کند.
13. برای صفحه‌ای که فقط iframe، اسکریپت، یا هیچ مدیای مستقیمی ندارد دکمهٔ ساختگی «پخش» نمایش داده نشود؛ نیاز به API رسمی ثبت شود.
14. نصب نسخهٔ `.preview041` کنار نسخه‌های قبلی، بدون حذف/پاک‌کردن داده‌ها.
