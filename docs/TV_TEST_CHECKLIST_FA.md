# Pooyan TV v0.2 — آزمون دستگاه (پیش از تأیید)

هیچ‌کدام از آزمون‌های زیر هنوز روی دستگاه از این سورس ثبت نشده‌اند.

- [ ] ساخت GitHub Actions موفق (`assembleDebug` + `lintDebug`)
- [ ] APK v0.2-preview در کنار v0.1 نصب شده و چیزی حذف نشده است
- [ ] صفحهٔ اصلی native بدون WebView اجرا می‌شود
- [ ] دکمه‌های D-pad، OK و Back به‌درستی کار می‌کنند
- [ ] پوستر و متادیتای Cinemeta در چین (یا با مسیر اتصال مورد استفاده) دریافت می‌شود
- [ ] صفحهٔ فیلم و قسمت‌های سریال بدون crash باز می‌شود
- [ ] یکی از فیلم‌های Blender با Media3 باز و بیش از ۳۰ ثانیه پخش می‌شود
- [ ] ادامهٔ پخش یک فیلم در دقیقهٔ دو ذخیره و بازیابی می‌شود
- [ ] جست‌وجوی جهانی و علاقه‌مندی‌ها کار می‌کنند
- [ ] فیلمِ بدون لینک قانونی دکمهٔ پخش ساختگی ندارد
- [ ] خطای قطع اینترنت قابل فهم است و برنامه بسته نمی‌شود

برای هر آزمون باید زمان، نسخه، مدل تلویزیون و شواهد ADB/تصویر ثبت شود؛ وضعیت موفق بدون شواهد ثبت نشود.
