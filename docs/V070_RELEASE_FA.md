# Pooyan TV v0.7.0 — برنامهٔ انتشار آزمایشی

این نسخه بر مبنای v0.6.0 Premium است و مرکز نگهداری با بررسی به‌روزرسانی از GitHub، بررسی SHA256 و تطبیق امضای APK، نصب با تأیید Android، تنظیمات محدود منابع از فایل JSON عمومی، پشتیبان خانوادگی، تشخیص سلامت اتصال، پاک‌سازی کش موقت، نمایش اطلاعات واقعی موجود در JSON-LD و تنظیم موقعیت/سبک زیرنویس را اضافه می‌کند.

پیش‌شرط انتشار قابل‌آپدیت: تعریف چهار Secret امضای پایدار در GitHub Actions (به README_V070_FA.md مراجعه شود). نسخهٔ stable تنها زمانی منتشر می‌شود که این Secretها موجود باشند. کلید خصوصی نباید در مخزن قرار بگیرد.

**محدودیت مهم:** برنامهٔ v0.6.0 Preview با شناسهٔ `com.pooyan.namakadetv.preview060` و امضای Debug، مستقیماً به شناسهٔ stable v0.7.0 ارتقا پیدا نمی‌کند. نصب stable جداگانه انجام می‌شود؛ می‌توان با خروجی/import مجاز فعلی، داده‌های همان پروفایل را منتقل کرد. از پاک‌کردن نسخهٔ فعلی قبل از تأیید کارکرد نسخهٔ جدید خودداری کنید.

سیستم OTA قوانین تنها اعداد محدودِ تعداد تلاش و زمان cooldown را می‌پذیرد؛ هرگز کد، URL مقصد جدید، رمز، توکن، اسکریپت یا روش دور زدن دسترسی بارگیری نمی‌کند. برای فعال‌سازی، فایل config/source-rules-v1.json باید در شاخهٔ main منتشر شود.

این بسته یک PATCH سورس است؛ تأیید عملکرد واقعی تلویزیون/صدا، نصب و اجرای CI پس از اعمال هنوز لازم است. نتایج نسخهٔ v0.6.0 به‌عنوان شاهد کارکرد v0.7.0 محسوب نمی‌شود.
