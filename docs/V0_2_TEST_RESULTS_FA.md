# گزارش آزمون Pooyan TV 0.2 Preview

آزمون در ۲۰۲۶/۱۱/۱۵ روی Xiaomi MiTV-MFFU0 با Android 14 و API 34 انجام شد. شناسهٔ نسخهٔ آزمایشی `com.pooyan.namakadetv.preview` است. نسخهٔ 0.1 با شناسهٔ `com.pooyan.namakadetv` و versionCode برابر 5 همچنان نصب است. نصب‌های آزمایشی فقط بستهٔ Preview را به‌روزرسانی کردند.

بیلد کد `c3d2fdf` در [GitHub Actions](https://github.com/PooyanGhorbani/Pooyan-TV/actions/runs/43692290075) با JDK 17، Gradle 8.9، Android SDK 35 و Build Tools 35.0.0 ساخته شد. JDK 17 برای اجرای آزمون‌های آفلاین در Ubuntu/WSL نیز نصب شد. دانلود ابزارهای کامل Android روی PC کند و ناموفق بود و کامپایل APK در Actions انجام شد.

| آزمون | نتیجه |
|---|---|
| آزمون‌های Java | ۴۴ بررسی موفق در StreamDetector، PlaybackResumePolicy، CatalogPolicy، OpenFilms و PosterPolicy |
| نحو و نمادها | ۱۳ فایل Java بررسی شدند و آزمون‌ها موفق بودند |
| کامپایل و Lint | assembleDebug و lintDebug موفق، صفر خطا و ۱۳ هشدار |
| رابط | Viewهای بومی Android، صفحهٔ سینمایی، منو و کارت‌ها؛ WebView در کد نهایی وجود ندارد |
| اندازه‌بندی | بریدگی سربرگ در تراکم 320dpi اصلاح شد؛ اندازهٔ منطقی صفحه برای چیدمان مبنا قرار گرفت |
| کاتالوگ | فهرست فیلم، سریال و ژانر روی تلویزیون بارگذاری شد |
| تغییر مسیر Cinemeta | پاسخ 307 به دامنهٔ رسمی cinemeta-catalogs.strem.io دنبال می‌شود؛ HTTPS و دو دامنهٔ مجاز بررسی می‌شوند |
| پوستر و جزئیات | پوستر و شرح Interstellar روی تلویزیون نمایش داده شدند؛ نبود تصویر در منابع بیرونی همچنان ممکن است |
| جست‌وجو | Interstellar و From از API در خود برنامه نتیجه دادند |
| فصل و قسمت | فصل‌های From نمایش داده شدند؛ انتخاب فصل ۳، قسمت S3 E1 را نمایش داد |
| علاقه‌مندی | Interstellar اضافه شد و در کتابخانه با پوستر ظاهر شد |
| کنترل | جابه‌جایی D-pad، OK، Back، مکث، ادامه و فرمان جلو بردن پخش آزمایش شد |
| تمام‌صفحه | فریم‌های واقعی ویدئو در تمام صفحه ثبت شدند |
| زیرنویس | فایل WebVTT آزمایشی مخزن انتخاب شد و متن آن روی فریم ویدئو دیده شد |
| ادامهٔ تماشا | زمان و مدت هر شش فیلم در دادهٔ محلی ثبت شد و پس از نصب مجدد Preview با حفظ داده باقی ماند |
| صدا | آغاز AudioTrack در Logcat مشاهده شد؛ شنیدن خروجی بلندگو و کیفیت شنیداری از راه ADB قابل تأیید نبود |
| پایداری | در آزمون کوتاه دستگاه، ورودی crash مربوط به Preview در بافر crash مشاهده نشد |

هر شش آدرس اولیهٔ فیلم‌های Blender نامعتبر بودند یا HTML برمی‌گرداندند. آدرس‌های تازه از API رسمی video.blender.org استخراج شدند. هر شش منبع با درخواست Range پاسخ 206 و Content-Type برابر video/mp4 دادند. Big Buck Bunny، Sintel، Tears of Steel، Spring، Sprite Fright و Agent 327 روی تلویزیون به وضعیت آمادهٔ Media3 رسیدند. موقعیت ثبت‌شده برای همهٔ آن‌ها از صفر بیشتر بود. آزمون‌ها کوتاه بودند و کل طول فیلم‌ها تماشا نشد.

هشدارهای Lint مربوط به نسخه‌های جدیدتر SDK و Media3، جهت افقی ثابت، سیاست انتقال داده، شکل و محل آیکن و قالب‌بندی بعضی متن‌ها هستند. این پیش‌نمایش با SDK 35 و Media3 1.6.1 آزمایش شد. هشدارها مخفی نشده‌اند و گزارش اصلی Lint همراه خروجی ذخیره شده است.

APK منتشرشده یک بیلد debug آزمایشی است که با کلید ثابت محلی Preview دوباره امضا شده است. فایل کلید در مخزن یا Release قرار نگرفته است. خروجی خام هر اجرای Actions ممکن است امضای debug متفاوتی داشته باشد؛ برای به‌روزرسانی نصب فعلی باید از امضای ثابت همین Preview استفاده شود.

محدودیت‌های آزمایش شامل کیفیت شنیداری، تماشای کامل فیلم‌ها، پایداری چندساعته، منابع DRM، همهٔ انواع HLS/DASH و زیرنویس SRT است. منبع عمومی VTT آزمایش شد. محتوای تجاری Cinemeta متادیتا است و برای پخش به منبع مجاز کاربر نیاز دارد. هیچ حساب یا نشانی خصوصی برای انتشار در کد درج نشده است.
