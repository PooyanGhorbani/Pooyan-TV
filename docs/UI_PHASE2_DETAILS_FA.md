# فاز دوم UI — صفحهٔ جزئیات

شاخه: `ui/phase2-details`، بر پایهٔ `ui/phase1`
وضعیت: آزمایشی؛ انتشار APK و نصب روی تلویزیون انجام نمی‌شود.

## طراحی و پیاده‌سازی

- چیدمان native مطابق فریم `03 · DETAILS` در Figma: پس‌زمینهٔ سینمایی، scrim برای خوانایی، عنوان و فرادادهٔ کاتالوگ، اقدام اصلی و فهرست علاقه‌مندی.
- تصویر پوستر کاتالوگ برای backdrop و پوستر اصلی استفاده می‌شود، چون مدل فعلی عنوان تصویر backdrop جداگانه ندارد. اطلاعات سال، ژانر، امتیاز، بازیگران و مدت فقط در صورت وجود نمایش داده می‌شوند.
- برای سریال‌ها، فصل‌های موجود از دادهٔ واقعی قسمت‌ها مرتب می‌شوند؛ قسمت نامشخص با عنوان «فصل‌بندی‌نشده» باقی می‌ماند و فصل/قسمت جدیدی ساخته نمی‌شود.
- کارت‌های قسمت به‌صورت افقی و قابل فوکوس نمایش داده می‌شوند. انتخاب فصل و برگشت از صفحهٔ قسمت باید فوکوس را حفظ کنند.
- ادامهٔ تماشا و نوار پیشرفت از `LibraryStore` محلی خوانده می‌شوند. موارد مشابه تنها از `DiscoveryPolicy` و ژانرهای واقعی کاتالوگ می‌آیند.
- مسیرهای Player، updater، شناسهٔ بسته، پروفایل‌ها و تنظیمات نسخه تغییر نمی‌کنند.

## تست و پیش‌نمایش

Workflow: `.github/workflows/ui-phase2-details.yml`

- Build، تست‌های JVM، Android lint، و تست‌های Worker بدون deploy اجرا می‌شوند.
- instrumentation کامل روی AVD `tv_1080p` و AVD `tv_1080p` با override منطقی `1280x720` اجرا می‌شود. این دو تست وضوح واقعی AVD اختصاصی `tv_720p` محسوب نمی‌شوند.
- شبیه‌ساز از صفحهٔ native جزئیات تصویر `emulator-detail.png` می‌گیرد و آن را همراه گزارش‌ها به‌عنوان artifact ذخیره می‌کند.
- AVD اختصاصی `tv_720p` همچنان یک تشخیص جداگانه است. خطای قبلی ناپدیدشدن QEMU/قطع ADB حل‌شده فرض نشده است؛ این job برای حفظ دادهٔ تشخیصی و جلوگیری از مسدودکردن دو محیط پایدار، اجازهٔ شکست دارد.

نتیجهٔ واقعی تست‌ها و لینک artifact پس از اجرای GitHub Actions در گزارش تحویل ثبت می‌شود.
