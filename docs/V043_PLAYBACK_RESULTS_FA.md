# نتیجهٔ واقعی v0.4.3 — پخش بومی FarsiPlex

مبنای کد: `c3d45ca` از `dev/v0.4.2-deepseek`؛ شاخهٔ جدید: `dev/v0.4.3-native-playback`.
گزارش قبلی `REAL_PLAYBACK_RESULTS_FA.md` پیش از تغییر خوانده شد و شواهد پخش واقعی نسخهٔ 0.4.2 در آن دست‌نخورده باقی است.

## تغییرات
- جریان عمومی فرم watch → POST /play/ → صفحهٔ مجاز همان سایت → /jwplayer/ → JSON منتشرشدهٔ file حفظ شد؛ امضا و query لینک تغییر نمی‌کند. هیچ URL ویدئوی واقعی ثابت نشده است.
- بررسی مستقل و محدود بدنهٔ رسانه پیش از ارائهٔ پخش حفظ شد. بررسی تکراری یک لینک در دریافت جزئیات حذف شد.
- خطای فارسی برای نبود منبع عمومی، timeout، خطای شبکه، پاسخ 401/402/403 و اطلاعات نامعتبر پلیر اضافه شد؛ URLهای موقت و جزئیات استثنا در پیام خطا منتشر نمی‌شوند.
- فهرست قسمت‌ها در صورت وجود #seasons از همان بخش خوانده می‌شود؛ لینک‌های قسمت در sidebar با قسمت‌های سریال مخلوط نمی‌شوند. تصویر کنار لینک در سطر قسمت و شمارهٔ فصل/قسمت نیز استخراج می‌شود.
- در آزمون زنده، og:image قسمت‌ها روی میزبان خارج از سیاست تصویر بود. کاور واقعی img.cover روی خود farsiplex.com به‌عنوان جایگزین اضافه شد؛ دامنهٔ تصویری جدیدی مجاز نشده است.
- بازگشت از قسمت به سریال، فوکوس را به همان قسمت برمی‌گرداند. این رفتار بررسی کد شده، ولی روی TV برای v0.4.3 آزمایش نشده است.

## آزمون HTTP واقعی
آزمون opt-in از همان کلاس Java بومی استفاده می‌کند، نه بازنویسی resolver در زبان دیگر. DeepSeek، Worker زنده، لینک دستی، حساب کاربر و کوکی مرورگر استفاده نشدند. دریافت رسانه به 4096 بایت برای هر منبع محدود است؛ فایل کامل دریافت نشده است. HEAD نیز جداگانه بررسی شد.

| عنوان | کشف قسمت | نتیجهٔ رسانه | HEAD / نوع / Range |
|---|---|---|---|
| Tars Az Ashk Haye Vaghei | فیلم | MP4 با امضای بایت معتبر | 200 / video/mp4 / bytes |
| Harchi To Begi | فیلم | MP4 با امضای بایت معتبر | 200 / video/mp4 / bytes |
| Meymoone Mast | ۱ قسمت | قسمت ۱: MP4 با امضای بایت معتبر | 200 / video/mp4 / bytes |
| Ostokhan Sooz | ۴ قسمت | قسمت‌های ۱ و ۲: MP4 با امضای بایت معتبر | 200 / video/mp4 / bytes |

در اجرای اول پوستر دو فیلم و دو سریال HEAD=200 داشت؛ پوستر جزئیات قسمت‌ها خالی بود و همین یافته موجب اصلاح کاور شد. در اجرای نهایی، کاور هر سه قسمت نیز HEAD=200 داد؛ پوستر همهٔ هفت ردیف گزارش HTTP=200 است. در این نمونهٔ محدود، منبع رسانهٔ ناموفق مشاهده نشد؛ آزمون‌های ساختگی نبود فرم، دسترسی ممنوع، redirect خارجی، timeout و probe ناموفق را پوشش می‌دهند. هیچ نتیجه‌ای دربارهٔ سایر عناوین یا اعتبار آیندهٔ لینک‌ها گرفته نمی‌شود.

## تست‌ها و حدود تأیید
- JDK 17، Android SDK 35، Gradle 8.9؛ assembleDebug، testDebugUnitTest و lintDebug در GitHub Actions با موفقیت اجرا شدند: ۱۶ تست Java، صفر شکست/خطا/skip؛ Lint: صفر خطا، ۱۴ هشدار موجود (از جمله متن‌های hardcoded).
- ۸ تست رگرسیون جدید بومی: فرم و JSON شامل punctuation، حفظ query، توقف روی 403، redirect خارجی، نبود فرم، probe ناموفق، timeout بدون افشای URL، سطر قسمت/کاور.
- تست‌های قبلی parser و HTML5، ۵۵ بررسی مستقل سیاست‌ها/فوکوس و ۹ تست resolver-worker نیز اجرا می‌شوند. فایل‌های Worker تغییر نکرده‌اند و هیچ deploy انجام نشده است.
- HTTP موفق و امضای MP4 شاهد سازگاری کامل کدک یا پخش تصویر/صوت نیست. HLS/DASH واقعی در این نوبت آزمایش نشده‌اند.
- طبق درخواست، هیچ نصب یا تغییری روی TV انجام نشد؛ Media3، صدا، seek، ریموت و پایداری v0.4.3 روی دستگاه تأیید نشده‌اند. تنها شاهد واقعی قبلی Media3 مربوط به قسمت ۱ میمون مست در نسخهٔ 0.4.2 است.
- مسیر عمومی سایت تأییدشده، اما API/مجوز یکپارچه‌سازی تجاری FarsiPlex تأیید نشده است. ورود، اشتراک، DRM و محدودیت‌های دسترسی دور زده نمی‌شوند.
