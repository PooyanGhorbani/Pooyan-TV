## اصلاحات
سورس ZIP به شاخهٔ توسعه منتقل شد. کلاس‌های کاتالوگ قدیمیِ به‌ارث‌رسیده از main حذف شدند. برچسب قسمت‌ها، شمارهٔ فصل و قسمت عمومی سایت را حفظ می‌کند. workflow ساخت، تست، Lint، artifact و prerelease اضافه/پیکربندی شد. رابط بومی حفظ شد و WebView اضافه نشد.

## ساخت و تست
JDK17، SDK35، Gradle8.9 و Media3 1.6.1 در CI تنظیم شدند. assembleDebug، testDebugUnitTest و lintDebug موفق‌اند. 38 بررسی مستقل سیاست URL/پوستر/پخش/resume، بررسی نمادها و سینتکس 13 فایل Java موفق‌اند. تست‌های JUnit parser نیز در وظیفهٔ unit test اجرا شدند.

## تحقیق FarsiPlex و محدودیت پخش
صفحات عمومی /movie/، /tvshow/ و صفحهٔ سریال قابل دریافت بودند. /wp-json/ فهرست routeهای WordPress و افزونه‌های dooplay/dooplayer را منتشر می‌کند. وجود route یک مجوز استفاده یا API رسمی پخش مورد تأیید برای Pooyan TV نیست. مسیرهای پخش محافظت‌شده، توکن‌ها و player scripts استخراج نشدند و احراز هویت، DRM یا محدودیت دسترسی دور زده نشد.

یک API رسمی مستند و مجوز یکپارچه‌سازی پخش برای این برنامه در بررسی انجام‌شده تأیید نشد. پخش FarsiPlex آزمایش و تأیید نشده است. پوستر و کاتالوگ کار می‌کنند؛ این موضوع به معنای کارکرد streaming نیست. پلیر Media3 فقط با لینک مستقیم مجاز که کاربر وارد کند فعال می‌شود. در این نسخه لینک مجاز FarsiPlex در دسترس نبود، بنابراین پخش واقعی آن اعلام نمی‌شود.

این APK پیش‌نمایش Debug است. کلید امضای پایدار برای به‌روزرسانی‌های آینده هنوز تنظیم نشده و ممکن است امضای ساخت‌های CI متفاوت باشد. نصب 0.1 با شناسهٔ اصلی هدف هیچ عملیات حذف یا ارتقا قرار نگرفت. فایل‌های خصوصی یا اطلاعات شبکه در این گزارش درج نشده‌اند.
