# گزارش نصب و آزمایش Pooyan TV v0.1

تاریخ: ۱۵ نوامبر ۲۰۲۶. دستگاه واقعی Xiaomi MiTV_MFFU0 با Android 14، نمایشگر 1920×1080 و WebView 116.0.5845.195. اطلاعات شبکه و شناسهٔ اتصال عمداً درج نشده‌اند.

## ساخت و فایل نصب

- سورس APK نصب‌شده: commit `c97f58f8fcbe56fca0d528c6a43d718732ef5324`.
- [ساخت موفق و artifact](https://github.com/PooyanGhorbani/Pooyan-TV/actions/runs/43685934959).
- [APK منتشرشده](https://github.com/PooyanGhorbani/Pooyan-TV/releases/download/v0.1/pooyan-tv-v0.1-debug.apk).
- SHA256: `805ed7c84ea6b98fa13066cb1ffb6e0a3b3623baf21776f77864e30ac894c0b2`. دانلود با این مقدار تطبیق داده شد.
- JDK 17، Gradle 8.9، AGP 8.7.3، SDK 35 و Media3 1.6.1 در GitHub Actions پیکربندی شدند. ابزارهای سنگین محلی کامل نصب نشدند؛ APK واقعی در CI ساخته شد.
- ۱۰۷ بررسی منطقی، بررسی سینتکس ۱۵ فایل Java و XML، assembleDebug، assembleDebugAndroidTest و lintDebug موفق بودند. موفقیت Lint به معنای نبود همهٔ هشدارها نیست.

## نصب واقعی

ADB مجاز به تلویزیون متصل شد. `adb install -r` نتیجهٔ `Success` داد. اجرای `am start -W` نتیجهٔ `Status: ok` و اجرای سرد حدود ۲٫۳ ثانیه داد. فرایند برنامه مشاهده شد. Package Manager مقدار versionName=0.1، versionCode=5، minSdk=23 و targetSdk=35 را تأیید کرد. هیچ برنامه‌ای حذف و هیچ داده‌ای پاک نشد. یک APK آزمایش نیز برای آزمون دستگاه نصب شد.

| علاقه‌مندی و جست‌وجوی محلی | آزمون افزودن/یافتن علاقه‌مندی آزمایشی و تطبیق جست‌وجوی فارسی موفق بود؛ فقط همان ورودی آزمایشی حذف شد |
| Media3 و تمام‌صفحه | نمونهٔ عمومی رسمی AndroidX `media/mp4/sample.mp4` از raw.githubusercontent.com واقعاً نمایش داده شد؛ Logcat رمزگشای `c2.mtk.avc.decoder` و ۲۹ فریم رندرشده را ثبت کرد؛ نمونه حدود یک ثانیه بود |
| خطای منبع | نمونهٔ Google و نمونهٔ W3C روی TV خطای HTTP 403 دادند؛ پیام خطا و گزینهٔ بازگشت به سایت نمایش داده شدند |
| WebView | صفحات برخی سایت‌ها رندر شدند؛ پخش HTML5 نمونهٔ Google جلو نرفت و آزمون شکست خورد؛ پخش و تمام‌صفحهٔ HTML5 تأیید نشده‌اند |
| پیشرفت پخش | نوشتن اطلاعات پخش روی دستگاه مشاهده شد؛ نمونهٔ کوتاهِ تمام‌شده موقعیت صفر دارد؛ بازیابی موقعیت غیرصفر برای ویدئوی بلند روی TV تأیید نشده است؛ منطق resume تست واحد موفق دارد |
| پایداری | در مسیرهای انجام‌شده FATAL EXCEPTION برنامه مشاهده نشد؛ این تضمین نبود کرش در همهٔ شرایط نیست |

آزمون instrumentation پخش Google در دو تلاش به نتیجهٔ موفق نرسید؛ تلاش دوم خطای منبع 403 را آشکار کرد. آزمون HTML5 نیز ناموفق بود. آزمون هفت‌سایت صرفاً زنده‌ماندن Activity را بررسی می‌کند و نتیجهٔ OK آن به معنای دسترسی کامل به هر هفت سایت نیست. بررسی مستقل UI با انتظار و تصویر انجام شد.

در جابه‌جایی اولیه، صفحهٔ Just a moment نیز دیده شد. هیچ CAPTCHA، احراز هویت یا DRM دور زده نشد. دسترسی کامل و پخش تمام منابع تأیید نشده است.

## محدودیت انتشار و ادامهٔ کار

APK یک Debug prerelease واقعی است. امضای پیش‌فرض CI ممکن است در ساخت‌های آینده تغییر کند؛ برای ارتقای پایدار، کلید امضای خصوصی ثابت و پشتیبان امن لازم است. فایل Release تأییدشده به‌طور خودکار بازنویسی نمی‌شود؛ ساخت‌های جدید artifact جداگانه دارند. در ناسازگاری امضا، اسکریپت نصب توقف می‌کند و برنامهٔ قبلی را حذف نمی‌کند.

پیش از اعلام تکمیل آزمون محصول، پخش و ادامهٔ تماشای یک ویدئوی بلند قابل دسترس، پخش HTML5 و تمام‌صفحهٔ آن، HLS/DASH واقعی، جست‌وجوی سراسری و دسترسی کامل سایت‌های محدودشده باید روی دستگاه بررسی شوند.
