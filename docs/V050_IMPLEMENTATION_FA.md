# Pooyan TV v0.5.0 — Cinematic Multi-Source Preview

## وضعیت واقعی تحویل
این بسته **سورس پیش‌نمایش v0.5.0** است، نه APK آماده یا نسخهٔ تأییدشده روی دستگاه. دسترسی GitHub در این جلسه فقط خواندنی بود و Android SDK/Gradle این محیط موجود نبود؛ بنابراین بیلد Android، lint و تست واقعی تلویزیون هنوز انجام نشده است. فایل `Publish-v0.5.0.ps1` راهی برای ساخت رایگان APK با GitHub Actions، بدون Codex، ارائه می‌کند.

سورس کامل این بسته از ZIP محلی نسخهٔ قدیمی v0.4.2 بازسازی شده و منطق FarsiPlex پخش موفق v0.4.3 از فایل‌های رسمی مخزن به آن افزوده شده است. **برای حفظ دقیق آخرین بیس‌لاین v0.4.3، اسکریپت انتشار فقط فایل‌های مشخص‌شده در `v050-overlay-files.txt` را روی شاخهٔ فعلی `dev/v0.4.3-native-playback` اضافه می‌کند؛ فایل‌های Worker و دیگر کلاس‌های پخش و تست‌های فعلی را بازنویسی نمی‌کند.**

## v0.4.4: پایهٔ چندمنبعی
- `UnifiedRepository`: ترکیب دو مسیر فهرست عمومی به‌صورت همزمان؛ اختلال منبع کمکی نباید دادهٔ سالم منبع اصلی را پاک کند.
- `NamakadeCatalog` و `NamakadeRepository`: دریافت **فقط فرادادهٔ عمومی** از صفحات فهرست فیلم و سریال با allowlist محدود دامنه؛ این منبع هنوز تأیید پخش مستقل ندارد.
- `CatalogMerge`: ادغام عناوین دارای نام/نوع یکسان با نگه‌داشتن گزینه‌های جایگزین و اولویت مسیر پخش قبلاً سالم.
- منطق موفق `FarsiPlexPlayback` برای فرم عمومی watch، JW JSON منتشرشده و CDN از baseline حفظ می‌شود. توکن ساختگی، دور زدن اشتراک، DRM یا ورود حساب انجام نمی‌شود.

## v0.4.5: کشف و جست‌وجوی یکپارچه
- جست‌وجو در دو منبع عمومی فعال و ادغام نتایج.
- `CatalogIdentity`: نرمال‌سازی حروف فارسی/عربی و نشانه‌گذاری برای کاهش تکرار.
- پشتیبانی از علاقه‌مندی نام‌های چندمنبعی، حفظ قالب داده‌های قدیمی برای عنوان‌های منبع اصلی و تغییر نکردن مسیرهای مجاز پخش.
- تلاش محدود برای منبع جایگزین تنها در صورت وجود تطابق معتبر و لینک پخش مستقیم تأییدشده.

## v0.5.0: طراحی سینمایی
- حذف کادر بزرگ رنگی و متن تبلیغی قدیمی بالای خانه.
- هیروی تمام‌عرض با پس‌زمینهٔ پوستر، فید تیره و دکمه‌های پخش/اطلاعات.
- تم تیره، رنگ تأکیدی قرمز، متن سفید، پوستر بزرگ، فوکوس واضح کنترل تلویزیون.
- ردیف «ادامهٔ تماشا» از سابقهٔ محلی همان نصب (در صورت وجود موقعیت ذخیره‌شده).
- کارت‌های قسمت با کاور، عنوان، نوار فوکوس و بازگشت به انتخاب قبلی.
- حذف نام وب‌سایت‌های تأمین‌کننده از ناوبری، صفحهٔ خانه، عنوان فهرست، توضیح حقوقیِ عادی و پیام وضعیت.
- جزئیات شبکه و نام منابع همچنان **داخل کد/مستندات** به‌عنوان منشأ فنی موجودند، نه در صفحات مرور کاربر.

## محدودیت‌هایی که نباید پنهان شوند
- فهرست عمومی منبع کمکی قابل مشاهده بوده، اما ساختار HTML و پخش تلویزیونی آن در زمان ساخت روی دستگاه کاربر تست نشده؛ بنابراین پخش خودکار آن **تضمین نشده است**.
- F2Media به دلیل نبود آدرس رسمی پایدار و مسیر مجاز پخش تأییدشده، در این نسخه به عنوان منبع پخش فعال وارد نشده است. اضافه‌کردن آدرس فرضی می‌تواند امنیت و ثبات برنامه را خراب کند.
- هیچ APK واقعی در این محیط ساخته نشده و موفقیت CI/Media3 دستگاه هنوز نامشخص است.
- بستهٔ `.preview050` شناسهٔ متفاوت دارد، بنابراین سابقهٔ تماشای preview043 را به صورت خودکار به نسخهٔ جدید منتقل نمی‌کند. نسخه‌های نصب‌شدهٔ پیشین دست‌نخورده خواهند ماند.
- تشخیص نام فارسی/لاتین کاملاً هوشمند نیست و هنوز احتمال عنوان‌های تکراری وجود دارد.
- آدرس‌های موقتی ویدیو می‌توانند با گذشت زمان تغییر کنند؛ برنامه هنگام بازکردن جزئیات تازه resolve می‌کند.
- این پروژه مجوز تجاری/عمومی استفاده از حقوق آثار و منابع ثالث را تأیید نکرده است.

## بررسی‌های انجام‌شده در این محیط
- `bash scripts/verify-offline.sh` با موفقیت اجرا شد (تست‌های Java مستقل، سیاست URL/تصویر، ادغام عناوین، بازرسی نمادها و تحلیل نحوی همهٔ ۲۶ فایل اصلی Java).
- هیچ اقدامی در TV، Cloudflare Worker یا repository زنده انجام نشده.
- Android SDK، Gradle، تست‌های JUnit کامل Android و آزمایش UI/صدا/پخش تلویزیون نیازمند CI و دستگاه هستند.

## ساخت بدون Codex
۱. فایل ZIP را روی رایانهٔ ویندوزی باز کن؛ Git for Windows با دسترسی push به مخزن خودت نیاز است.
۲. فایل `Publish-v0.5.0.ps1` را اجرا کن. این فایل شاخهٔ سالم v0.4.3 را می‌گیرد، فقط فایل‌های overlay را روی شاخهٔ **جدید** `dev/v0.5.0-cinematic` commit و push می‌کند، بدون force-push.
۳. GitHub Actions بیلد را اجرا می‌کند: https://github.com/PooyanGhorbani/Pooyan-TV/actions
۴. فقط پس از **موفقیت CI** فایل `Pooyan-TV-v0.5.0-Cinematic-Preview` را از Artifacts بگیر. نصب روی TV و تست واقعی با تصمیم خود کاربر انجام شود.
